## Решения по открытым вопросам

Ответа команды не было, поэтому до её решения принял так:

1. **Отели реальные** (OpenStreetMap и сайты отелей), у каждого факта ссылка, цены помечены «Демо-цены». Вымышленных названий нет.
2. **Отзывов нет**: строки вроде «31 из 38 отзывов» не выводятся.

Если команда решит иначе, менять нужно только `backend/flow/data.py`.

## Что не сделано или урезано

- **Необычные направления** из каталога (Териберка, Хибины, Шерегеш, Плёс, Зеленоградск, Кисловодск, Архыз, Листвянка). Отелей для них в снимке OSM нет, а Overpass из среды разработки недоступен. Агент честно отвечает «нет в данных» и предлагает похожие места. Есть Тбилиси, Ереван, Калининград, Иркутск (как «ворота Байкала»), Горно-Алтайск, Минеральные Воды. Чтобы добавить новые места: `python scripts/refresh_regions.py` с новым регионом в `REGIONS`, затем строка в `backend/flow/data.py::DESTINATIONS`.
- **Матрица расстояний** (пешком и на машине по дорогам) есть только для Сочи. В остальных местах расстояния по прямой с такой подписью; районы оцениваются по редакционному описанию. Построить матрицу: `scripts/build_poi_matrix.py` (нужен доступ к OSRM/ORS).
- **Рейтинг отеля и факты вроде «120 м до пляжа», «клуб с 4 лет»** — таких данных нет; «Вид на море» всегда «не подтверждено».
- **Фильтры «свободные номера» и «детский клуб по возрасту»**: наличие — модель, возраста допуска в клуб в данных нет.
- **«С собакой в Калининград»**: ни один из 10 отелей OSM не подтверждает размещение с животными — агент говорит об этом и предлагает ослабить условие.
- **Координаты «Казань Экспо»** — ориентир по карте, их нужно сверить.
- **Фото отелей** — иллюстрации с подписью.
- **Сборка Docker** проверена с оговоркой: Docker Hub в среде разработки отвечал 429, поэтому базовые образы тех же версий взяты с зеркала `mirror.gcr.io`, а для pip/npm добавлен сертификат прокси песочницы (только во временной копии Dockerfile). Образ собирается, работает под uid 10001, healthcheck — healthy, e2e `linear.spec.ts` проходит на контейнере. Сам `docker compose up --build` с чистого компьютера нужно проверить команде.
