## Исправления

Убран max-width:520px у оболочки, добавлены desktop/tablet/mobile стили. Исправлены хранилище MCP, Origin/auth/body/rate guards и пустые ответы на notifications. Добавлен ключевой для дешёвого демо keyless OSRM foot с кэшем и ограничением частоты; ORS остаётся альтернативой. Оптимизатор сохраняет обязательные требования исходного запроса. Источник маршрутов берётся из снимка вместо фиксированной подписи ORS.

## Запуск

Из папки проекта: `docker compose up --build -d`, затем http://127.0.0.1:8080 . Если порт занят, PowerShell: `$env:APP_PORT='8087'`, затем та же команда. Проверенный экземпляр на этом компьютере: http://127.0.0.1:8087 . Демо работает без ключей. Для расширенного диалога параметры LLM описаны в README и .env.example.

Исходные пользовательские SQLite, .env, виртуальные окружения, node_modules и тестовые runtime-данные исключены из нового архива. Демо-факты и маршруты лежат в backend/datasets. Первый запуск создаёт новую базу.

## Что НЕ подтверждено / не готово

Это работающий прототип, не закрытое полностью широкое ТЗ и не глобальный production-продукт. Не реализованы живые тарифы/наличие/оплата, расписания рейсов и проверка стыковок, многорегиональный проверенный каталог, аккаунты, общий лимитер между репликами. LLM без предоставленного ключа не проверялась; без неё есть локальный разбор. Автономный выбор MCP-инструментов моделью не реализован; инструменты доступны внешнему агенту, подбор приоритетов использует заранее полученные реальные снимки.

Overpass может не отвечать; нет гарантии всех live-запросов. ORS не тестировался с ключом. Бесплатные публичные API не означают безлимитный коммерческий сервис. План масштабирования и условия — MCP_FREE_API_GUIDE.md. Слово «везде» применимо к переносимости Docker, а не к готовому покрытию всех стран.

Дополнительно: те же 6 Chrome/Playwright сценариев прошли против Docker на 8087 (27,3 с). Контейнер работает от непривилегированного пользователя app (UID 10001).
