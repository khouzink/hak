# Сверка с ТЗ «О!дин запрос»

Источник — переданное командой ТЗ v1.0 от 24.10.2026. Этот файл не копирует текст задания. Статус относится к локальной рабочей копии; официальные критерии жюри и его оценка неизвестны.

| Область | Состояние | Оставшаяся работа |
|---|---|---|
| Понимание запроса | Локальный разбор, допущения и вопросы; отдельная поддержка примера на английском. Скрипт `python scripts/eval_intake.py` проверяет выбранные поля в 18 примерах ТЗ. | 18/18 примеров проходят выбранные проверки; оценка неполная, не все поля проверены. Неизвестный возраст сохраняется отдельно и запрашивается до расчёта. Нет независимого набора. |
| Направления | Существуют каталог направлений, поиск и климатические данные с источником. | Не реализованы все правила отбора и «почти подходящих» направлений; покрытие стран и проверенных услуг ограничено данными. Требование уникальной страны противоречит примеру с двумя городами Египта. |
| Поездка, время и деньги | Сохраняется мини-калькулятор; есть модельное расписание, часовые пояса, итог, ограничения и проверки. | Это демонстрационная модель, не реальные рейсы и цены. Нужна независимая сверка всех состыковок и правил по приложению к ТЗ. |
| Пересборка и заказ | Есть предложения изменений с подтверждением, пересчёт, симуляция заказа и отмена, проверка версии. | Не все операции, замки и сравнение изменений из ТЗ реализованы. Нет реальной покупки, и она не требуется. |
| Безопасность и устойчивость | Есть изоляция сессий, проверки входа и MCP, тесты гонок, ограниченный локальный нагрузочный тест. | Нужны углублённые проверки публичного размещения, живого LLM и внешних источников; фильтр инструкций не гарантирует безопасность модели. |
| Сдача | Docker Compose собран и запущен на отдельном порту, healthcheck успешен; есть README и пример окружения. | На чужой машине не проверено; скринкаст, публикация в конкурсный репозиторий и тег submission не выполнены. |

## Необходимые следующие шаги

Сверить доступное техническое приложение с реализацией и согласовать противоречия ТЗ. Поэтапно реализовать недостающие Must-операции, независимую проверку пакетов, полную оценку понимания и метрики раздела 12; затем повторить серверные, браузерные, нагрузочные и чистую Docker-проверки. Не выдавать демонстрационные данные за реальные предложения. Имя и возраст путешественников не заменяют паспорт или платёжные данные.
